What's in the box

Open in this order

The architect draws the room. The building services engineer draws the pipes, ducts and outlets. When the two drawings are laid over each other, things sometimes end up in the same place. The student finds five planted clashes against the clock, then writes a technical query (TQ) to the design manager, the way a site engineer would.

  • Host guideAim, run sheet, questions to ask
  • InvestigateOverlay the drawings and find the clashes

  • Portfolio pageReflection and host sign-off
Why this activity: it uses edited project drawings, as Dr Ponton suggested, and shows how the design manager, building services engineer and site engineer pass information to each other through a TQ. It reuses on any project by editing that project's drawings.

Host guide

Read in 3 minutes

Aim: the student learns why drawings from different designers have to be coordinated, how to read a plan and a services drawing together, and how a TQ moves a problem from site to the design team.

Before the session

Three questions to ask

  1. Why do two professional designers end up drawing things in the same place?
  2. What would happen if nobody spotted this clash until the wall was built?
  3. Who should answer your TQ, and how quickly?
